# Espaço do Equilíbrio

Landing page desenvolvida para apresentar o Espaço do Equilíbrio, um ambiente voltado à saúde, ao bem-estar e à qualidade de vida.

O projeto foi desenvolvido com foco em uma navegação intuitiva, organização das informações e experiência do usuário.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Layout responsivo para diferentes tamanhos de tela.
- Menu de navegação adaptado para dispositivos móveis.
- Apresentação de serviços e tratamentos.
- Detalhamento interativo dos serviços.
- Seção de produtos.
- Apresentação de profissionais e avaliações.
- Seção de perguntas frequentes (FAQ).
- Integração com WhatsApp para contato.
- Animações durante a navegação pela página.
